# Release Notes: v0.3.2

Jinguzhou 0.3.2 is a patch release for the 0.3 agent ecosystem line.

Highlights:

- kept the MCP, LangChain, LlamaIndex, and OpenAI Agents integration surface from `0.3.0`
- stabilized the CLI overwrite test across Python, Click, and Typer versions
- updated package, Docker, npm, Helm, and validation references to `0.3.2`

This release is intended to replace the failed `v0.3.1` automation run with a clean patch version.
